# Notification sounds (placeholder descriptions)
# These audio files need to be added to assets/sounds/ directory:
# 1. soft_bell.mp3 - Gentle, calm bell sound (200ms)
# 2. digital_beep.mp3 - Sharp, attention-grabbing beep (300ms)
# 3. chime.mp3 - Melodic chime sound (500ms)
# 4. urgent_buzz.mp3 - Strong vibrating buzz (400ms)
# 5. nature_birds.mp3 - Calm bird chirping (800ms)
#
# All sounds should be:
# - MP3 format
# - 30 seconds maximum duration when looped
# - Mono or stereo
# - Sample rate: 44.1kHz or 48kHz
#
# Recommended sources:
# - Freesound.org
# - Zapsplat.com
# - Pixabay.com
# - Notification sound libraries

# To add sounds to your Flutter app:
# 1. Create assets/sounds/ directory
# 2. Download/create the 5 MP3 files above
# 3. Add to pubspec.yaml under assets section
